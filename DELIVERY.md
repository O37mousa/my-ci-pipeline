## 📞 Support & Troubleshooting

### If Jenkins Fails to Build

**Check Docker socket permissions:**
```bash
ls -l /var/run/docker.sock
# Should show: rw-rw-rw- or similar
sudo chmod 666 /var/run/docker.sock
```

**View Jenkins logs:**
```bash
docker logs -f jenkins-lts | grep -i error
```

### If Lint Fails

**Test locally first:**
```bash
npm run lint
npm run lint -- --fix  # Fix automatically
```

**Check ESLint config:**
```bash
cat .eslintrc.json
```

### If Build Still Fails

**Detailed troubleshooting in:**
- CHECKPOINT.md → Troubleshooting section
- README.md → Troubleshooting section
- COMMANDS.md → Phase 6: Troubleshooting Commands
